第一次怎么配置（约 10 分钟，只做一次）

A. 把页面挂到 GitHub Pages（拿到网址）

  1. 打开 github.com/new 新建仓库，名字填 hardware-plan，选 Public，点 Create repository。
  2. 在仓库页点 Add file → Upload files，把 hardware-learning-plan.html 拖进去，上传前把文件名改成 index.html，然后点 Commit changes。
  3. 进仓库 Settings → Pages：Source 选 Deploy from a branch，Branch 选 main、目录选 / (root)，点 Save。
  4. 等大约 1 分钟，刷新这个 Pages 页面，顶部会出现你的网址，形如
    https://你的用户名.github.io/hardware-plan/

B. 建一个只能读写 Gist 的 token

  1. 打开 github.com/settings/tokens → Generate new token (classic)
  2. Note 填 hw-plan；Expiration 选 No expiration（或 1 年，到期再换）
  3. 只勾最上面那个 gist，其他一个都别勾
  4. 点 Generate token，复制那串 ghp_...（只显示这一次）

C. 连接

  1. 把 token 粘到上面的输入框，点 连接。看到「已同步」就成了。
  2. 在手机或另一台电脑打开同一个网址，粘同一个 token，点连接 → 进度自动拉下来。
这个 token 等于你 Gist 的钥匙。它只存在你这台设备的浏览器里，不会上传到任何地方，也 不要写进仓库、不要发群里。它只有 gist 权限，碰不到你的代码仓库（除了 Gist 什么都干不了）。 想作废随时回上面那个页面点 Delete。
